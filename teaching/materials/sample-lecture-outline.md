# Sample Lecture Outline

This outline demonstrates how I structure a 60-minute session focused on introducing a new topic while leaving time for student practice.

## Session Goals
- Introduce the core concept with motivating examples
- Check for understanding with targeted questions
- Provide scaffolded practice problems for teams

## Timeline
| Time | Activity | Purpose |
| ---- | -------- | ------- |
| 0-5 min | Welcome & prior knowledge poll | Surface existing ideas |
| 5-15 min | Mini-lecture with live demo | Establish core concept |
| 15-25 min | Think-pair-share prompt | Encourage peer explanation |
| 25-45 min | Group practice worksheet | Apply concept collaboratively |
| 45-55 min | Whole-class debrief | Surface strategies & misconceptions |
| 55-60 min | Exit ticket | Gather feedback & plan follow-up |

## Materials Needed
- Slides or whiteboard for visual summary
- Worksheet with tiered problems
- Timer visible to students

## Assessment Touchpoints
1. Quick poll at the start
2. Circulate during group practice to listen for reasoning
3. Review exit ticket responses to tailor next session
